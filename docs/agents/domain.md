# Domain context

This is a single-context research project. Read `CLAUDE.md` for collaborator
decisions and `doc/` for the manuscript methods. Read `CONTEXT.md` and relevant
`docs/adr/` records if present; their absence does not block local work.

Distinguish extant species grand means used for fitting from within-site
species means used for primary prediction. Primary fossil placement uses each
site occurrence's age and formal taxonomy. MAP is in cm; modelling uses its
natural logarithm, and site fossil MAP averages back-transformed species
predictions. LMA is a separate pipeline.
